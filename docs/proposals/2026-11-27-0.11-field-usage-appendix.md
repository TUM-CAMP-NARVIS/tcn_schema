# tcn_schema 0.11: field usage by the five consumers (appendix)

2026-11-27. Companion to `2026-11-27-0.11-schema-housekeeping-proposal.md` §4.5.

This appendix covers every field of every **kept** custom struct whose producers never write real data. Each field
is either **NEVER-SET** (no producer touches it) or **CONSTANT** (every producer writes a fixed value). Where the
field gets fixed values, the appendix names them. It also lists the code that reads such a field: each reader is a
fix the owning project must make before 0.11.

Fields not mentioned here are written from real data.

**Consumers and refs:**
- tcnart v3 (`v3/`, master 20868f07)
- SQE engine (main 6b484e8): its own `crates/sqe-calibrate` counts as a producer; `src/examples` and tests do not.
- HTA (main e8c8366e)
- web controller (cdr-xcdr2 = main fe5c135, plus working tree)
- IVA (master 33a8f66)
- sqe_client_cpp headers
- tcn_schema's own `src/sqe`

Not scanned: ROS 2 types, the types deleted in proposal §4.1–4.3, and conversation_msgs beyond what #36 already
lists.

Please check the entries for your project and comment on the PR where an entry is wrong. In paths, `S/` is the SQE
engine repository root.
