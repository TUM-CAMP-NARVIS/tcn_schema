# tcn_schema 0.11, Plan 1: Layout and Tooling — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare the repository for the 0.11 IDL changes without changing a single byte on the wire. That means:
- documentation in its final place;
- code generated outside the source tree;
- one package table that drives CMake and conan;
- an IDL parser that emits `types.json` and `enums.json`;
- an IDL lint with a baseline;
- generated round-trip tests plus golden byte files for every top-level type.

**Architecture:**
- **Python, stdlib only,** under `tools/idl/`: a hand-written IDL parser for the subset this repository uses, with a table generator, a lint and a round-trip-test generator on top.
- **CMake:** one function, `tcn_add_idl_package()` in `cmake/TcnPackage.cmake`, replaces the boilerplate in the 14 per-package `CMakeLists.txt`. It reads the package table `cmake/tcn_packages.json`, which `conanfile.py` reads too.
- **Tests:** generated C++ round-trip tests use the existing `CHECK` style (no gtest); the Python tools use `unittest`.

**Tech Stack:** CMake ≥ 3.18, fast-dds-gen 3.0.0, fast-cdr 2.0.0, conan 2, Python 3 (stdlib only; `pytest` is not installed).

**Spec:**
- `docs/proposals/0.11-decisions.md` (§3 Structure, O5–O9; §10 Next steps);
- `docs/2026-11-27-0.11-schema-housekeeping-proposal.md` §5.2 (O5–O9) and §7 (work order). Task 1 moves this file under `docs/proposals/`.

## Global Constraints

- **The wire must not change in this plan.** Encoding stays `CdrVersion::DDS_CDR` with encapsulation `00 01`. IDL contents are not edited, except the docs moves in Task 1.
- **The installed package must not change** in layout or header contents. The baseline is taken in Task 2, Step 1, and compared in later tasks. The only additions allowed are `share/tcn_schema/types.json`, `share/tcn_schema/enums.json` and `share/tcn_schema/packages.json`.
- **The toolchain stays** at fast-dds-gen 3.0.0 / fast-cdr 2.0.0 (decision §2, "Toolchain").
- **Python:** stdlib only. Run tools with `python3 -I`; tests with `python3 -m unittest discover -s tools -p 'test_*.py'`.
- **C++:** C++17. No new third-party dependency (the existing test style uses `check.h`/`CHECK`).
- **Conan components keep their names** (`builtin_interfaces`, …, `sqe_contract`, `sqe_session`). Library names stay `tcn_schema_<pkg>`.
- **Build commands** (from the repo root; the baseline build takes about 1 minute):
  - `conan install . -s build_type=Release --build missing && cmake --preset conan-release && cmake --build build/Release -j16`
- **Commits:** end every message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Work on branch `0.11-plan1-layout`.

## Review Focus

1. **A consumer building from the conan package** (not the source tree) must find every header at the same path as in 0.10.7. Covered by the install-tree diff in Tasks 2 and 4.
2. **A parallel build** (`-j16`) after removing `CMAKE_BUILD_PARALLEL_LEVEL 1` must not race on generator outputs or the shared included IDL (e.g. `std_msgs/msg/Header.idl` is regenerated by several package runs). Covered by Task 2, Step 6 (three clean parallel builds).
3. **IDL the parser does not expect.** All of these exist today and must parse:
   - `@verbatim` strings spanning lines;
   - forward declarations (`union ParameterValue;` in `Requests.idl`);
   - `typedef uint8 uint8__16[16];` (UUID);
   - `const` inside `*_Constants` modules;
   - `@default (value=0.0)`.

   Covered by Task 3, Step 1, "every file parses, 449 top-level types".
4. **Unions in the round-trip generator.** `SRStreamTrigger`, `SISPlanOp`, `SISRelationStreamHandle`, `ParameterValue` and `TrackingTargetConfig` must default-construct and round-trip. Covered by Task 6, Step 1.
5. **Docs links after the move.** README, the MIGRATION index and cross-references between the proposals must resolve. Covered by Task 1's link check.

### Task 3: IDL parser and the generated tables

**Files:**
- Create:
  - `tools/idl/__init__.py`;
  - `tools/idl/model.py` (dataclasses);
  - `tools/idl/parser.py`;
  - `tools/idl/tables.py`;
  - `tools/idl/__main__.py` (CLI);
  - `tools/idl/tests/__init__.py`, `tools/idl/tests/test_parser.py`, `tools/idl/tests/test_tables.py`;
  - `tools/idl/tests/fixtures/*.idl`.
- Modify: `CMakeLists.txt` (generate and install the tables).

**Interfaces:**
- Produces (`tools/idl/model.py`):
  - `Member(name: str, type: str, optional: bool, array: list[int] | None, annotations: dict[str, str])`. `type` is fully qualified for named types; primitives are spelled as in IDL. Bounded forms: `sequence<T, N>`, `sequence<T>`, `string<N>`, `string`.
  - `Struct(name, members: list[Member], extensibility: str, annotations)`. `extensibility` is one of `"final" | "appendable" | "mutable" | "default"`; `"default"` means no annotation.
  - `Enum(name, enumerators: list[tuple[str, int]], extensibility)`.
  - `Union(name, discriminator: str, cases: list[tuple[list[str], Member]], extensibility)`. Labels are enumerator names or `"default"`.
  - `Typedef(name, type: str, array: list[int] | None)`.
  - `Const(name, type, value: str)`.
  - `IdlFile(path: str, package: str, kind: str, includes: list[str], decls: list[Struct | Enum | Union | Typedef | Const])`.
    - `path` is relative to `src/dds/<family>/`, e.g. `tcnart_msgs/msg/Types.idl`;
    - `kind` is `msg | rpc | action`;
    - `decls` carry fully qualified names, e.g. `tcnart_msgs::msg::SensorType`;
    - forward declarations are dropped.
  - `Schema(files: list[IdlFile], family: dict[str, str])`, mapping package → `"ros2" | "tcn"`.
- Produces (`tools/idl/parser.py`): `parse_file(path: Path, rel: str) -> IdlFile` and `load_schema(dds_root: Path) -> Schema` (walks `ros2/` and `custom/`, later `tcn/`).
- Produces (`tools/idl/tables.py`): `build_types(schema) -> dict` and `build_enums(schema) -> dict`, written as JSON with `indent=1` and `sort_keys=True`:
  - `enums.json` = `{"schema_version": "<conan version>", "enums": [{"name", "file", "package", "extensibility", "enumerators": [{"name", "value"}]}]}`.
  - `types.json` = `{"schema_version": …, "types": [{"name", "kind": "struct|union|enum|typedef|const", "package", "family", "file", "extensibility", "members": [...], "discriminator"?, "cases"?: [{"labels", "member"}]}]}`.
    - `name` is the fully qualified wire type name.
    - Each member is `{"name", "type", "optional", "array"}`.
    - Types are listed in file order.
- CLI: `python3 -I -m tools.idl tables --dds-root src/dds --version <v> --out <dir>` writes `<dir>/types.json` and `<dir>/enums.json`.

### Task 5: IDL lint with a baseline

**Files:**
- Create: `tools/idl/lint.py`, `tools/idl/lint_baseline.txt`, `tools/idl/tests/test_lint.py`, `docs/idl-style.md`.
- Modify: `CMakeLists.txt` (`add_test(NAME idl_lint …)` when `TCN_SCHEMA_BUILD_MSG_TESTS` is ON).

**Interfaces:**
- Produces: `lint(schema, files_text: dict[str, str]) -> list[Finding]` with `Finding(rule: str, file: str, line: int, message: str)`.
  - CLI: `python3 -I -m tools.idl lint --dds-root src/dds --baseline tools/idl/lint_baseline.txt [--update-baseline]`.
  - It exits 1 when there is a finding not in the baseline, **or** a baseline entry that no longer occurs. A stale baseline must shrink.
  - Baseline lines are `rule<TAB>file<TAB>symbol`, without line numbers, so edits elsewhere in a file do not churn the baseline.
- Rules, with the ids used in the baseline, each from #39 O5 / decisions §2:
  - `basename-unique`: no file basename twice in one package across msg/rpc/action.
  - `file-pascalcase` (tcn family only).
  - `include-guard`: every file has `#ifndef X` / `#define X`, with X derived from the path: `<PKG>_<KIND>_<FILE>_IDL`, upper-case.
  - `enum-first-unknown` (tcn only): the first enumerator ends in `_UNKNOWN` or `_NONE` (E6).
  - `enum-prefix` (tcn only): every enumerator starts with the enum name in UPPER_SNAKE (O5).
  - `extensibility-explicit`: tcn structs, unions and enums carry `@appendable` or `@final`; ros2 types carry `@final` (E1, E2, E7).
  - `no-enums-module`: no `module enums`.
- `docs/idl-style.md` lists these rules, one paragraph each, citing the decision ids.
