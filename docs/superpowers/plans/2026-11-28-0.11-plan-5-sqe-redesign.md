**Goal:** Land #35 as decided, so the SQE types change once: all N, R, H, E, S2–S6 and §6 items with F3/F4 and
every `sqe_msgs` enum in E6/O5 form (no `sqe_msgs` lint entry left); the `tcn_types` foundations of decisions §3/§8

## For SQE review (not blockers; the plan proceeds with these choices)

1. `SISStatus` and every new enum start with `…_UNKNOWN` (E6 over R1's order), so `0` is never success; the
   `SISReason` list and the old → new status mapping below.
2. Stream start with no route answers `REJECTED` + `NO_PATH`; a running stream that loses its route goes `PENDING` +
   `WITHDRAWN`; sample `NO_VALUE`/`TOO_OLD` are `OK` + `SISSampleOutcome`.
3. Keys: `/sis/relation/sample` becomes `/sis/stream/sample` (so `/sis/relation/**` disappears with H4); `target/*`
   stays on client keys (routing by client prefix reaches the serving engine without knowing its id).
4. Unscoped `sqe/{engine}/info` answers `SISEngineInfoRequest` with `SISEngineSummaryReply`; join answers
   `SISJoinReply`; both carry `SISEngineCapabilities`.
5. Capability names `[a-z0-9_]{1,64}`, initial set `sample`, `domain`, `rational_lens`, `marker_domain`; a client
   refuses a malformed name.
6. `kProtocolBreak = 99`, provisionally the engine's B-number for the 0.11 break.
7. `client_scope` contains a client id when equal to it or a prefix ending at a `/` chunk boundary; `""` contains all.
8. `handle` is opaque; the engine may keep `handle == data_topic`, and `status_topic`/`plan_topic` stay
   `{data_topic}/status|/plan` on its side.
9. `sequence` counters are per topic (status, plan, output), start at 1, gapless per handle; plans are published as
   `SISPlanNotification`.
10. `SRDistortionModel` has `UNKNOWN` before `NONE`; `metric_radius` is the normalized image-plane radius
    (`sqrt(x²+y²)` at `z = 1`) within which the model is valid.
11. `UNKNOWN` fusion/reoptimise/evaluation/trigger values are refused `REJECTED` + `MALFORMED`; `FUSED`/`FILTERED` are
    refused `REJECTED` + `UNSUPPORTED`.

- **N2a text form** (contract library and engine, one vector file `src/sqe/vectors/frame_ref.tsv`):
  `local:<fragment>/<name>`, `global:<name>`, `domain:<domain>/<name>`, each optionally + `[instances]`. Fragment and
  domain use the fragment alphabet (`check_fragment`), the name the identifier alphabet (`check_identifier`, no `/`).
  Parse in this order, first failure wins:
  1. empty → `empty`;
  2. if the text contains `[`: it must end with `[instances]` and contain no other `[` → else `malformed_selector`;
     strip it, selector `INSTANCES` (else `FRAME`);
  3. scheme = text up to the **first** `:`; no `:` → `missing_scheme`; not exactly `local`/`global`/`domain` →
     `unknown_scheme`;
  4. `global`: body containing `/` → `unexpected_owner`; else `check_identifier(body)`;
  5. `local`/`domain`: split at the **last** `/`; none → `missing_owner`; `check_fragment(owner)`, then
     `check_identifier(name)`.

  `format` is the inverse; text → ref → text is exact. A LOCAL ref with an empty owner ("this fragment") exists only
  inside a join on the wire; it has no text form, and `FrameRef` refuses it.

## Review Focus

1. **Stored or hard-coded ordinals:** every `sqe_msgs` enum shifts, and `0` now means `UNKNOWN`, not OK/ACTIVE/
   GENERIC. Engine persistence, TS/C# mirrors and "`status == 0`" checks invert silently. Pinned by the enum map with
   old/new values (Task 1), the C++ mirror check (Task 1, 7) and `reply_header` of a zeroed reply being not `ok()`
   (Task 7).
2. **N2a drift between C++ and Rust** (`/` in a fragment, `:` in a name, the suffix): pinned by the installed vector
   file, run by the C++ test (Task 6) and named as mandatory for the engine in the migration log (Task 8).
3. **A subscriber that still decodes the data topic as `TargetTrackingMessage` or composes `/status`:** pinned by
   `Handle` exposing only reply-given topics and `SISRelationOutput` registered (Task 7); the old composers stay
   engine-only.
4. **Absent read as default** (no transform → identity, no covariance → "exact", no `park_reason`, no handle):
   pinned by goldens with absent members and reviewed presence bytes (Tasks 3, 4).
5. **Empty-owner LOCAL refs outside a join, and scope prefixes without a chunk boundary:** pinned by
   `FrameRef::from_wire` refusing an empty owner and `ClientScope` tests (Task 6).
