  - names unique within a set;
  - `kind` defaults to `tree`; a tree has exactly one root, every parent is a joint of the set, and the parent graph

  - `rest_pose: t_pose` requires every bone's `rest_dir`, unit length within 1e-9;
  - `extends` is a prefix of joints and bones;
  - `source` is in {`OBSERVED`, `DERIVED`, `DEFAULTED`};
  - ordinals are exactly 1..N;
  - joints ≤ 64 (the `HumanPose.joints` bound); SMPL sets have `joints − 1` ≤ 54 (the `SmplParams.pose` bound);
  - against `previous`, a set whose joints, bones or rest pose changed must have a higher `version`.
